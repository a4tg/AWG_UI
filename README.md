# AWG Manager MVP

Простой веб-интерфейс для сценария:

- есть 3 сервера AWG2.0 в Docker `amnezia-awg2`;
- на одного пользователя нужно быстро выдать 3 ключа;
- менеджер не должен делать лишние ручные шаги.

## Что уже умеет

- хранит пользователей в SQLite;
- показывает 3 сервера из `config/servers.json`;
- создаёт пользователя через UI;
- одной кнопкой подключается по SSH к каждому серверу и выпускает комплект из 3 конфигов;
- обновляет `awg0.conf` и `clientsTable` внутри контейнера `amnezia-awg2`;
- хранит и отображает выданные конфиги в веб-интерфейсе.

## Быстрый старт

```powershell
python app.py
```

После запуска откройте:

`http://127.0.0.1:8080`

## Структура

- `app.py` - точка входа
- `backend/app.py` - HTTP API и SQLite
- `backend/provisioner.py` - генерация комплекта ключей
- `config/servers.json` - список серверов
- `web/` - интерфейс

## Важный момент

Теперь `backend/provisioner.py` работает с реальными серверами по `ssh -> docker exec`.

Что важно перед первым боевым запуском:

1. На машине, где запускается панель, должен быть настроен SSH-доступ к серверам без интерактивного ввода.
   Можно использовать `ssh-agent` или указать путь к приватному ключу в `config/servers.json` через `identity_file`.
2. Формат клиентского `.conf` собран по данным из `amnezia-awg2`; желательно сверить его с одним экспортом из AmneziaVPN перед массовой выдачей.
3. Рекомендуется добавить авторизацию в панель и сделать бэкап `awg0.conf`/`clientsTable`.
