# AWG Manager

Веб-интерфейс для управления `AWG 2.0`-серверами в контейнерах `amnezia-awg2`.

Теперь панель работает в модели:

- есть несколько серверов `AWG 2.0`
- у каждого сервера своя страница с клиентами и ключами
- ключ выдаётся на конкретный сервер
- для ключа можно задать `Годен до` или сделать его бессрочным
- просроченные ключи автоматически блокируются и удаляются из рабочего AWG-конфига на сервере

## Что уже умеет

- хранит клиентов и ключи в SQLite
- позволяет добавлять сервер через UI по `host + user + password`
- при первом подключении ставит локальный `~/.ssh/id_ed25519.pub` в `/root/.ssh/authorized_keys`
- после этого работает с сервером по SSH-ключу
- проверяет SSH-доступ ко всем серверам
- выдаёт `.vpn` для AmneziaVPN и резервный `.conf`
- даёт вручную блокировать, разблокировать, продлевать и удалять ключи

## Установка

```powershell
python -m pip install -r requirements.txt
```

## Запуск

```powershell
python app.py
```

Открыть:

`http://127.0.0.1:8080`

## Как добавить сервер

1. Открыть панель.
2. В левой колонке заполнить форму `Добавить сервер`.
3. Указать:
   - название
   - `host`
   - `root`
   - пароль
4. Нажать `Добавить и настроить`.

Пароль используется только для первого входа и установки вашего локального SSH-ключа. В конфиге проекта он не сохраняется.

## Что нужно на локальной машине

- установлен `Python 3`
- существует локальный SSH-ключ:

```powershell
dir $env:USERPROFILE\.ssh
```

Ожидается хотя бы:

- `C:\Users\artem\.ssh\id_ed25519`
- `C:\Users\artem\.ssh\id_ed25519.pub`

Если ключа нет:

```powershell
ssh-keygen -t ed25519 -f $env:USERPROFILE\.ssh\id_ed25519
```

## Структура

- `app.py` - точка входа
- `backend/app.py` - HTTP API, SQLite, статус ключей, сроки действия, автоблокировка
- `backend/provisioner.py` - SSH, bootstrap серверов, выпуск и отключение ключей на AWG
- `config/servers.json` - сохранённые серверы
- `web/` - интерфейс
